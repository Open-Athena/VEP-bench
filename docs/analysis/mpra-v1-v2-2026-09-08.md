MPRA v1-to-v2 diagnostic, Sol medium, 2026-09-08
================================================

The dataset comparison shows two plausible contributors: including weak or uncertain effects through SIGN+MIN eligibility, and changing which significant variants receive weight under score-space sampling. MIN inclusion alone does not explain the observed decline.

Both versions contain the same 16 regulatory elements, 50 variants per element, with unchanged reference sequences, assay context, reporter context, and prompt wording. The template version changed. Only 69 of 800 source genomic allele keys overlap between selected sets. Normalized allele duplicate exclusion also changed.

| Selected-panel property | v1 | v2 |
| --- | ---: | ---: |
| SIGN variants | 800 | 370 |
| MIN variants | 0 | 430 |
| Absolute measured effect below 0.1 | 69 | 216 |
| Median barcode support | 511.5 | 233.5 |
| Variants with source p-value >= 0.05 | 0 | 223 |
| Deletions | 34 | 60 |
| Mean Spearman | 0.291159 | 0.191766 |
| Mean Pearson | 0.221651 | 0.195659 |

The canonical CADD VCF header defines SIGN as sufficient barcode support plus p < 1e-5, and MIN as sufficient barcode support without passing that significance criterion. Selected v2 SIGN p-values are all below 1e-5 and selected MIN p-values all above it. MIN does not imply a true zero effect or failed measurement QC. QUAL remains excluded. The arbitrary absolute-effect threshold 0.1 above is descriptive, not a proposed eligibility rule or biological null interval.

Weak effects and lower measurement support plausibly make fine rankings less reproducible. The source study explicitly discusses experimental noise affecting near-zero estimates: https://www.nature.com/articles/s41467-019-11526-w . Canonical header checked at https://kircherlab.bihealth.org/download/CADD-development/v1.7/validation/regseq/SatMut.all.F9.vcf.gz . This is a hypothesis about part of the drop, not an identified causal contribution or an estimated noise ceiling.

Score-space coverage did not uniformly increase absolute score spread versus v1: within-panel score standard deviation decreased in 10/16 elements, and min-to-max range decreased in 9/16. Anchors are recomputed on the expanded SIGN+MIN population, whereas v1 sampled rank quantiles from SIGN only. Coverage of the new population and greater absolute dynamic range than the old selected set are different properties.

Eight elements improved in Spearman and eight declined. The largest declines were:

| Element | v1 Spearman | v2 Spearman | v2 MIN count | v2 SIGN-only Spearman |
| --- | ---: | ---: | ---: | ---: |
| LDLR | 0.446 | -0.126 | 15/50 | -0.298 |
| IRF6 | 0.394 | -0.062 | 14/50 | -0.129 |
| TCF7L2 | 0.478 | 0.061 | 38/50 | 0.406 |
| MYC rs6983267 | 0.213 | -0.133 | 38/50 | -0.134 |

LDLR and IRF6 together contribute -0.0642 to the mean Spearman change of -0.0994, about 65% of the net drop. Their measured-score standard deviations increased, yet their new significant variants also rank poorly. This implicates which strong-effect variants were selected as well as weak-effect inclusion. TCF7L2 is more consistent with dilution by weak/uncertain variants: SIGN-only Spearman is 0.406 versus 0.061 across all 50. Subset scores recompute ranks within each smaller subset; they are diagnostic and are not additive components or controlled ablations.

Deletions are unlikely to be the main explanation. They were already present in v1. Restricting scoring to SNVs gives v1 mean Spearman 0.288860 and v2 0.191462, nearly the same decline as the full panels. v2 SNV-only mean Pearson is 0.196192 versus 0.195659 for the full panels.

No additional model evaluations or controlled ablations were launched for this diagnostic.

Reproduction and provenance
---------------------------

This analysis is retained on `codex/issue-62-sampling-analysis` and is not intended
to merge into `main`. The benchmark protocol itself was merged separately in
[PR #64](https://github.com/Open-Athena/VEP-bench/pull/64).

The [compact inputs](mpra-v1-v2-2026-09-08/inputs.json.gz) preserve both versions'
selected allele keys, effects, predictions, source filters, p-values and barcode
support. The [provenance manifest](mpra-v1-v2-2026-09-08/provenance.json) records
the source commits, question digests, original result digests and archive hashes.
This archive remains sufficient to verify the diagnostic after the previous
run disappears from the mutable HF `main` publication.

[Machine-readable results](mpra-v1-v2-2026-09-08/comparison.json) contain all
16 panel comparisons and subset diagnostics. [The checked VCF header](mpra-v1-v2-2026-09-08/source-vcf-header.txt)
records the upstream filter definitions. Source metadata was joined by candidate
ID within the corresponding version and panel; new question candidates matched
their committed sources exactly. The reference sequences and assay/reporter
contexts were also verified unchanged.

The previous published response archive's decompressed SHA-256 was checked
against the pre-rollout publication index. Correlations use average ranks for
ties, are computed within each element, then equally averaged. Full v1 means
matched the published index to 1e-12, and all v2 panel metrics matched scored
results to 1e-12. Subset results use their own subset ranks.

To check the archived inputs and recompute the reported diagnostics offline:

```bash
uv run --no-project python scripts/verify_mpra_comparison.py
```

The verification uses only the Python standard library and makes no network or
model calls. It checks metrics against the archived comparison with absolute
tolerance 1e-12, allowing floating-point differences from the original JavaScript
calculation. The archive contains existing analysis, not a new benchmark task.
